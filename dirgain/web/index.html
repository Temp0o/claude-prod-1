DirGain Calibrator

Measures whether your flicks overshoot or undershoot differently by direction, fits a per-direction gain profile only if the bias is statistically real, and checks with a blind A/B test whether the profile actually helps you.

Simulation mode: a synthetic user replaces your mouse. Results show the pipeline working, not your aim.

1. Setup

Uses raw mouse input (pointer lock, unadjusted movement). Turn off OS pointer acceleration for the most faithful numbers. Press Esc to stop a run.

2. Calibrate

Flick from the center to each target and click it. One block is 72 targets (24 directions × 3 distances, about 2 minutes). Your current profile is applied while you play, so each round measures what is left.

Profile

3. Validate (blind A/B)

192 targets in alternating blocks with and without the profile's directional shape (the control keeps the same average gain); you are not told which. The headline is time to hit. Pool several sessions: detecting a 20 ms effect needs roughly 280 trials per condition.

4. Export

profile.conf is read by the Linux daemon and the Windows adapter. Raw data lets you re-run the analysis later.
